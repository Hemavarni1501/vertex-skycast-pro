# 🌤️ Vertex SkyCast AI
**AI-Powered Weather Intelligence Dashboard**

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge.svg)](https://vertex-skycast-pro-tar3fmu9qpsoanfunvwjeu.streamlit.app/)

Vertex SkyCast AI is a next-generation weather dashboard that combines real-time meteorological data with the reasoning power of **Google Gemini 1.5 Flash**. Instead of just showing numbers, SkyCast provides actionable "AI Insights" and a conversational consultant to help users plan their day.

---

## 🚀 Live Demo
Check out the live application here: [Vertex SkyCast AI](https://vertex-skycast-pro-tar3fmu9qpsoanfunvwjeu.streamlit.app/)

## ✨ Key Features
* **Global Weather Search:** Instant access to weather data for any city worldwide via OpenWeatherMap API.
* **Gemini AI Insights:** Automatically generates punchy, context-aware outfit and planning advice.
* **AI Weather Consultant:** A built-in chat interface where users can ask complex questions like *"Is it a good day for a mountain hike?"* or *"Should I carry an umbrella today?"*
* **Dynamic UI:** Clean, responsive dark-mode interface with real-time metric updates.
* **Unit Conversion:** Seamlessly toggle between Metric (Celsius) and Imperial (Fahrenheit) systems.

## 🛠️ Tech Stack
* **Frontend:** [Streamlit](https://streamlit.io/) (Python Framework)
* **AI Engine:** [Google Gemini 1.5 Flash](https://ai.google.dev/) (Generative AI)
* **Weather Data:** [OpenWeatherMap API](https://openweathermap.org/api)
* **Backend:** Python 3.x
* **Deployment:** Streamlit Community Cloud

## 📦 Installation & Local Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Hemavarni1501/vertex-skycast-pro.git](https://github.com/Hemavarni1501/vertex-skycast-pro.git)
   cd vertex-skycast-pro
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Configure Secrets: Create a .streamlit/secrets.toml file and add your API keys:**
   ```bash
   OPENWEATHER_API_KEY = "your_openweather_key"
   GEMINI_API_KEY = "your_gemini_key"
   ```
4. **Run the app:**
   ```bash
   streamlit run app.py
  ```
